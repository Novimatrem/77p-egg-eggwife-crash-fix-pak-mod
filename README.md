# 77p-egg-eggwife-crash-fix-pak-mod

## Description

Pak mod file for 77p egg: Eggwife created by its lead programmer that fixes the freezing I was having upon respawn from a death, if you are stuck in an infinite loading screen after dying like I was, it could fix it for you. This happened to me whilst I was playing the Raging difficulty on the Factory2 level, and caused the game to become uncompletable, after a support and diagnostic process, and some testing, this mod package was created that solves the crash for me. This allows me to continue playing the game on my Apple Mac mini "M4" (2024) running macOS 26.2 Tahoe, under Crossover 26.3 (26.3.0.39832).

Seems to also help with Arena Mode, in addition to the campaign, reducing Arena Mode's chance of freezing/crashing too, which is fantastic.

This can also help fix a blackscreen freeze upon pressing to continue the game from the main menu.

## Installation

Place the file into: 

```/Steam/steamapps/common/77p egg Eggwife/eggwife/Content/Paks```

So the final path of the file becomes:

``/Steam/steamapps/common/77p egg Eggwife/eggwife/Content/Paks/EggCharacter_EnemyHealthBarComponent_P.pak``
